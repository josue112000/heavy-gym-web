# Heavy Gym (versión web)

Versión web instalable de Heavy Gym, para iPhone o cualquier celular.

**Instalar en iPhone:** abre el link en Safari → botón Compartir → **Agregar a pantalla de inicio** → Agregar.

Los datos se guardan solo en el celular de cada persona; este repositorio solo tiene la app.
Se genera desde el repositorio privado de Heavy Gym (`tools/build_app.py` → `dist/web/`); no edites estos archivos a mano.
